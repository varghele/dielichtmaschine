# v1.5.5 hardening plan

Branch `v1.5.5-hardening`, cut from `v1.5-focus-morphing` at `32dbd1e`
(2026-10-06). Source: the codebase assessment of 2026-10-06 (core/output,
GUI/visualizer, tests/tooling passes). This release fixes correctness,
threading and lifetime bugs and closes infra gaps; it adds no features.

## Ground rules

- One group per commit, each with the tests that prove the fix (a test
  that fails on the old code wherever the bug is testable).
- Gate per group: full `tests/unit` (-n auto), `tests/e2e`, `tests/visual`
  (serial) with no new failures against the recorded baseline, plus the
  demo export hashes (`scripts/export_hash_check.py`, PYTHONHASHSEED=0).
- Export output MAY change where a fix requires it (decision 2026-10-06);
  every hash change is named in the CHANGELOG entry of the group that
  caused it. Unchanged hashes are the default expectation.
- NO rendered-pixel changes: goldens exist only for win32 and cannot be
  regenerated on the Linux run. Anything that would move pixels is
  deferred to the roadmap instead.
- Structural refactors are planned, not done (see "Deferred" below).

Baseline (Linux, Python 3.13, PyQt6 6.11, offscreen): unit 3178 passed,
8 skipped, 1 env-dependent failure in `test_screensaver.py` (which of
two tests fails varies run to run); e2e 46 passed + 2 strict xfails;
visual 45 passed, 44 skipped (win32-only goldens).

## Deferred to the roadmap (structural, need the desk or a screen)

- Split `MainWindow` (project IO, autosave, LTC/GDTF controllers) and
  replace index-based tab lookup / `self.window()` calls with an app
  signal bus; dedupe the three config-load flows.
- Config load/save off the UI thread (drop `processEvents` progress hacks
  and the nested `QEventLoop` in `fixtures_tab`).
- Theme sweep: ~140 inline `setStyleSheet`, ~200 hex literals outside
  `theme_tokens.py` (`structure_tab.py:399` `color: white` breaks the
  light theme) plus a lint test. Moves pixels: needs Windows golden regen.
- i18n beyond the shell (600+ literal strings).
- `schema_version` + ordered migration steps for config files.
- Move Qt-dependent modules out of core packages (`auto/widgets`,
  `AudioWaveformWidget`, Qt timers in `timeline/` and `audio/`).
- `print` -> logging, audit of ~130 broad `except` blocks.
- Pinned constraints file for the Qt/GL stack so CI can run the win32
  goldens on the Windows job.
